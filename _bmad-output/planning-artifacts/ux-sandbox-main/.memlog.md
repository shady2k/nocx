topic: Filesystem sandbox UX
updated: 2026-10-05T17:35
---

- (decision) Approved scope: single Settings > Sandbox surface, Off/Enforce only; no Learn and no Statistics tab. Filesystem boundary only; network, Windows enforcement, SSH enforcement, container isolation, and full process/IPC isolation are not claimed.
- (decision) Authority is an immutable grant for one launch. Workspace and standard profiles are mutable defaults only. Apply/remove/relaunch replace the shell in the same pane after preview and confirmation; history, draft, pane/tab identity survive. Live process restoration reclaims the same session and grant; dead or unknown restore never falls back to an ordinary shell.
- (decision) Diagnostics report bounded observed attempts with source and precision, not proof of denial. Suggestions affect future launches only; no retry of the command. GUI file/git/completion actions remain user-trusted and agent-originated coordinator tools are refused for sandbox sessions.
- (event) UX spines finalized: DESIGN.md and EXPERIENCE.md capture approved sandbox visual and interaction contracts; no frontend files changed and no verification run.
