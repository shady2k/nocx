## Outcomes

- **O1: The terminal looks and behaves as it should** (`nocx-peg8e`, stage `nocx-peg8e.1`):
  over ssh a running `top` stays one block until it is quit; the right-hand panel remembers its
  state for each tab, also across a restart; the composer card sits inset from the pane's edges;
  a full-screen program's pinned header has no empty band above it. The fix for `top` is agreed
  with the owner after its cause is diagnosed, before code. **Check:** each behaviour's own e2e,
  chromium and webkit. **Success signal:** the owner stops reporting them.
  `Serves: daily-driving nocx without falling back (vision §9).`
- **O2: Remote sessions do not outlive their tabs** (`nocx-0la3i`, stage `nocx-0la3i.1`):
  closing a tab ends its session at once; a session whose client went away ends after a set
  number of days, a number in Settings, 3 by default, 0 for never. Starts with an ADR
  superseding "closing a tab is detach" and ADR-0104's "live shells are never swept".
  **Check:** an e2e closes a tab running a program and finds no such process on the host; a
  helper test with an injected clock. **Success signal:** no shells of closed tabs on the
  owner's host.
  `Serves: daily-driving nocx without falling back (vision §9).`
- **O3: Busy tabs and long output cost less** (`nocx-lp371`, stage `nocx-nqmjq`): PR #743 and
  PR #795 (with its draft #796) land with their before/after measurements, and a changing
  suffix redraws only the procedural borders that changed. **Check:** their own measurements
  and frame-budget specs. **Success signal:** input stays responsive with several noisy tabs.
  `Serves: a Ghostty-grade engine that handles modern agent TUIs (vision §1, §4).`
- **O4: An installed stable updates itself to the next stable** (`nocx-vh2hr`, stage
  `nocx-vh2hr.1`), carried from v0-8-2. macOS is accepted on the 0.8.2 nightly (in-app update,
  one Dock icon, visible progress); what remains is the stable-to-stable proof, which runs at the
  first promotion. **Check:** that proof's run. **Success signal:** a person on stable receives
  the next stable without reinstalling.
  `Serves: local updates users can verify and control (vision §8).`
