# v0-9 — Try the new agent engine without losing the existing assistant

The owner authorized this milestone on 2026-10-30 for the Pydantic integration
(`nocx-g9giy`). `nocx-g9giy.5` records its admission. This replaces the earlier
independent-workstream exception, not the existing assistant's authority model.
The work started from `origin/main` at `6062102f0` on
`feat/pydantic-agent-experimental`; the integration baseline advanced to
`ceb6bcc87`, then `3a67b18ec`, before final verification.

## What ships

A person can select the experimental Pydantic Deep Agents implementation in the
existing assistant settings, use the current Ask, endpoint Test, skill audit and
skill drafting workflows, and return new operations to Eino by switching it off.
The Go host still owns effects, approvals, credentials, history and cancellation.
The experiment is default-off and never silently falls back to another engine.

This milestone does not publish a release. ADR-0097's nightly and promotion
pipeline remains the delivery mechanism; promotion still requires its own
approval. No target date or performance improvement is promised.
