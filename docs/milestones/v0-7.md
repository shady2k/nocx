The live 0.6 work now being fixed ships as 0.7 carryover, alongside four selected outcomes: the shipped 0.6.1 duplicate-character regression stays fixed; compatible coordinator updates preserve live sessions; signed nightlies can be selected and promoted without rebuilding; and native fish integration works on macOS and Linux.
