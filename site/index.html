Linux · x86_64

Install with the nocx installer, which supports x86_64 Linux. It refuses macOS and unsupported architectures; macOS users should use Homebrew.

curl -fsSL https://nocx.dev/install.sh | sh

Or install manually from the AppImage:

chmod +x nocx-*-linux-amd64.AppImage
./nocx-*-linux-amd64.AppImage

Before your first launch

Can I bring my SSH connections?

Yes. nocx imports ~/.ssh/config and Tabby exports. Passwords and key passphrases stay in the vault; a connection references the secret.

What leaves my machine?

nocx connects to your hosts, your configured assistant endpoint and its own update checks. It has no cloud service of its own, product telemetry or cloud sync.

What is it built with?

Go for PTY, SSH and sessions; a backend-painted cell renderer for the terminal; CodeMirror 6 for input; SolidJS for the interface; Wails v3 for the desktop shell.

Does the API client have limits?

Responses are read up to 2 MiB. Bytes matching a stored secret are removed before display. A collection cannot access the password behind an SSH profile.
