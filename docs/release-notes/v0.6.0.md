# nocx 0.6.0

nocx 0.6 brings the terminal renderer and agent orchestration into the app. The terminal is painted from the backend's cell model, and coordinator/worker activity runs in nocx panes without herdr. This release also adds installation through the project's Homebrew tap.

## The terminal paints backend cells

The live terminal surface is rendered by nocx from screen frames supplied by the backend. It no longer uses xterm.js as its renderer or parser. The backend owns terminal emulation and the client paints the resulting cells, so the visible screen and the backend's terminal state have one source of truth. Input is sent as intent for the backend to interpret. The renderer supports the ordinary terminal interactions tested for this release, including typing, paste, IME composition, selection and copy. GPU rendering is not the model: the cell model is the contract, and the client paints it.

## Agent work runs in nocx panes

nocx now hosts the coordinator and its workers in panes. The coordinator starts and supervises worker work, and pane state and reports are visible in the app. This replaces the herdr-based working-day path: the 0.6 milestone's acceptance is a full working day in nocx with herdr stopped. It does not claim every herdr feature: worker execution remains on the VM, and agent-to-agent messages and workspace-neighbour messaging remain deferred. See the [0.6 milestone](../milestones/v0-6.md) for the exact scope and acceptance.

## Install on macOS

Install through the third-party Homebrew tap:

```bash
brew install --cask shady2k/nocx/nocx
```

The cask clears macOS quarantine after installation. This is an explicit trust decision: you trust the tap maintainers and accept that the cask removes the quarantine attribute. Read the [tap README](https://github.com/shady2k/homebrew-nocx) before installing. The app remains ad-hoc signed and is not notarized. Direct downloads from [GitHub Releases](https://github.com/shady2k/nocx/releases) still require the manual quarantine step described in the [README](../../README.md#install-macos).

## Still included

The existing local-first terminal, SSH manager, workspaces, session restore, sidebar tools, encrypted command history, vault, snippets, file transfer, API client and assistant remain part of nocx. For installation limits and recovery steps, see the [README](../../README.md).
