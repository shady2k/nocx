# nocx 0.8.1

A terminal that is working hard no longer gets in your way, an SSH session behaves like a local
one, running output stays still, and nocx speaks Russian.

## An SSH session works like a local one

- **Commands arrive as you typed them.** Five submits in a row all run; nothing is dropped,
  doubled or read as a job name (`fg: %apt-get: no such job` is gone), and long quoted lines
  keep every character.
- **`claude` and other agents start over SSH** the way they do locally.
- **An SSH tab opens without a silent wait.** The 20 to 30 seconds of a blank tab with a hidden
  cursor are gone.
- **A full-screen program such as `top` stays one block** from its start until you quit it.
- **A plain `sh` with no shell integration takes every command** you submit, not only the first.
- **Closing a tab ends its remote session at once**, and a session whose window went away ends
  by itself after a number of days you choose in Settings (3 by default).
- After an update, SSH started from a nocx pane keeps reaching hosts on your network.

## Running output stays still

- **A running block no longer jumps or shakes** while lines arrive: `apt update` is watchable.
- **If you scrolled up to read, you stay there.** New output no longer pulls you back to the
  top or to the live end, including after a full-screen program exits.
- A program's rows fit the block: nothing runs past the right edge, the header lines up with
  its output, and no row shows twice.
- Where an ordinary command's output was cut, a quiet marker sits in the history instead of the
  old missing-output card.
- A full-screen program's pinned header has no empty band above it, and `yazi`'s columns line
  up on every row, icons included.

## "The terminal is busy" is gone

nocx no longer refuses what you ask because it is busy. An action that takes a while waits;
past two seconds it appears in Operations with a Cancel button, and it goes away when it
finishes. A session with a lot of output no longer holds up typing, commands or updates in
your other tabs.

If you give up on an action that had to wait, nocx says truthfully whether it ran, and lets you
repeat it only if it did not. A disk or mount that stops answering costs you the action
waiting on it, not the window.

## Heavy output costs less

Hidden tabs stop painting while nobody is looking at them, and a closed tab gives back the
output it stored. Long output is captured and drawn with less work per frame.

## Opening an SSH session again is quick

A helper that is already installed on the host is no longer read back in full on every open.
The first open of a host still installs it.

## nocx speaks Russian

Settings → Interface → Language switches the whole window at once, with no restart. Text that
has no translation yet shows in English.

## Everyday fixes

- **The window opens where you left it**, at the size you left it.
- **A new tab opens right after the active one**, not somewhere else in the strip, and a tab
  drops a program's title once the program exits.
- **Closing every tab leaves you a working tab**, with its prompt and input line.
- **The right-hand panel remembers, for each tab, whether it was open**, across a restart.
- **The input line sits inset from the pane's edges** again.
- **Local icons draw** in programs such as `omp`, as they already did over SSH.
- After long work a new pane still starts, and after a restart or update no old background
  helper keeps running beside the new one.

## Updates

- A download survives a poor connection: it resumes, shows its progress, and only gives up
  when the connection has really gone silent.
- A failed update offers **Copy details**, with the real error and its step.
- An update replaces the running app cleanly on macOS, and on Linux the new window starts only
  after the old one has gone.
- Leftovers of an interrupted update no longer block the next one.
- On macOS the update shows its download progress, and the Dock keeps one nocx, the one you
  pinned.
- Nightly releases say what changed in plain words, and are numbered by their build.

## Terminal fixes

- **Keys typed right after Enter reach the command**, and Ctrl+C during a launch cancels it.
- **The AppImage no longer crashes on colour emoji** on Linux.
- **`clear` keeps what it cleared hidden**, and a running block keeps the rows it should when
  the prompt returns.
- **A failed host provider no longer offers a free-form connection** in its place.
- **A settings refresh keeps the page you are on** on screen.

## How to update

From 0.8.0, nocx offers this update inside the app. From 0.7.x, on macOS:

    brew upgrade --cask nocx

On Linux, run the install script again or download the new AppImage.

An update restarts the background process that owns your sessions, because this version changes
how the window talks to it: nocx warns you first, and running sessions end. Finish what is
running before you restart.
