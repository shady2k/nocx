Возвращается вывод программы, а не сама программа. Восстановление можно отключить в настройках.

Linux · x86_64

Установщик nocx поддерживает Linux x86_64. Он откажет на macOS и неподдерживаемых архитектурах; для macOS используйте Homebrew.

curl -fsSL https://nocx.dev/install.sh | sh

Или установите AppImage вручную:

chmod +x nocx-*-linux-amd64.AppImage
./nocx-*-linux-amd64.AppImage

До первого запуска

Можно перенести SSH-подключения?

Да. nocx импортирует профили и группы из Tabby. При подключении он разрешает псевдонимы из ~/.ssh/config, но не импортирует этот файл. Пароли и парольные фразы ключей можно связать с секретами в vault.

Какие данные уходят в сеть?

nocx обращается к вашим хостам, endpoint ассистента, который вы настроили, и проверяет собственные обновления. У продукта нет собственного облачного сервиса, продуктовой телеметрии или облачной синхронизации.

Что внутри?

Go для PTY, SSH и сессий; отрисовка ячеек по экранной модели бэкенда; CodeMirror 6 для ввода; SolidJS для интерфейса; Wails v3 для настольной оболочки.

Есть ли ограничения у API-клиента?

Ответ читается до 2 MiB. Байты, совпавшие с сохранённым секретом, удаляются до показа ответа. Коллекция не получает доступ к паролю за SSH-профилем.
